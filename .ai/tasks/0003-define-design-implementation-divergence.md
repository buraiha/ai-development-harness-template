# 設計書と現行実装の乖離への対応を定義

- Status: completed
- Depends on: none

## 目的と要求

ユーザーが合意した乖離レベル0〜3と、停止・確認する範囲を共通ハーネス原本へ反映する。

## 変更対象

AGENTS.md、.ai/common.md、.ai/guides/02-design.md、.ai/guides/03-implementation.md、.ai/guides/05-review.md、README.md、本task。

## 対象外・制約

導入先への一括反映、アプリの仕様判断や実装変更、pushは対象外。未追跡の.DS_Storeを保持する。ユーザー依頼に従い確認後にコミットする。

## 受け入れ条件・検証

乖離を行数で判定せず、根拠と未合意の仕様判断・影響で分類する。レベル2以上の依存範囲を停止し、独立した安全な作業は継続可能とする。重大領域を理由に承認済み作業の再承認を一律要求しない。相対リンク、文書整合、git diff --checkを確認する。

## 実施結果

- 原本の共通ルールへ乖離レベル0〜3、依存範囲の停止、確認時の提示内容と判断後の整合手順を追加した。入口と設計・実装・レビューガイドから参照する。
- 文書整合、14文書の相対リンク、git diff --checkを確認した。文書変更のためアプリ動作試験は対象外。
- ユーザー依頼に従い本変更をコミットする。pushと導入先への一括反映は行わない。
