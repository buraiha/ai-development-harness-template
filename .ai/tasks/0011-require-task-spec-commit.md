# タスク仕様確定後・実装前のコミット確認

- Status: completed
- Depends on: none

## 目的と要求

タスクの仕様が確定したら、確定内容を実装前にコミットすることを前提とする。未コミットのまま実装を指示されたら警告する。コミットの実行権限とは区別する。

## 変更対象

- AGENTS.md
- README.md
- .ai/common.md
- .ai/README.md
- .ai/guides/01-requirements.md
- .ai/guides/02-design.md
- .ai/guides/03-implementation.md
- .ai/guides/05-review.md
- .ai/tasks/README.md
- 本taskと試験結果

## 受け入れ条件

確定したtaskと関連仕様のコミット確認、未コミット時の警告、明示的な例外指示、無関係な変更の保護を整合して記載する。採番・リリース前コミットとは区別する。他プロジェクトへの適用・コミット・pushは行わない。

## 想定する検証

差分・リンク・git diff --checkと、警告条件のシナリオ確認。

## 追加・修正指示

ユーザーの「ハーネスに齟齬なく盛り込んでください」に基づき、承認状態、taskと実装の同時依頼、導入・要件・設計・レビューの各手順を整合させる。仕様文書の準備と成果物変更を区別し、コミットID確認を追記する。

作業完了時には、必要な検証と受け入れ条件の達成を確認してStatusを `completed` に更新することを明記する。厳密な状態遷移は追加しない。

## 実施結果

確定仕様の実装前コミット確認と未コミット時の警告を規範本文へ統合した。コミット・push・他プロジェクトへの適用は未実施。
