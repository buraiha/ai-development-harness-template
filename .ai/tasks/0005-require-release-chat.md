# AIによるリリースの専用チャット運用

- Status: completed
- Depends on: none

## 目的・範囲

AIによるリリースはユーザー指定のリリース専用チャットで行う共通ルールを追加する。人が手動で行うリリースは対象外。対象はAGENTS.md、.ai/common.md、.ai/project.md、README.md、本taskのみ。導入済みプロジェクトへの一括反映、実行制御の追加、コミット・pushは含めない。

## 受け入れ条件

- 専用チャット以外では実行を止めて移動を案内する。
- 専用チャットの指定・識別が不明なら推測で実行しない。
- 専用チャットでも操作内容の復唱とユーザー許可を必要とする。
- 手動リリースを制限せず、AIがコマンド実行を代行する場合はAIによるリリースとして扱う。
- 差分、参照先、git diff --checkを確認する。

## 実施結果・検証

共通ルール・入口・プロジェクト記入欄・READMEを更新。専用チャット、未指定時、操作確認、手動例外の記載と既存文書への参照先を確認。git diff --checkと変更5ファイルの末尾空白検査に合格。実行プログラムの変更はなく、AIが実際に従うことを自動試験で保証したものではない。コミット・pushは未実施。
