# Project Contract

このファイルには、AIの調査、変更、検証へ直接影響するプロジェクト固有の契約だけを記載する。

AIの共通行動規範は `AGENTS.md` と `.ai/common.md`、詳しい仕様や設計は `README.md` と `docs/` を参照すること。このファイルへ詳細なプロジェクト仕様や共通ルールを重複して記載しない。

## 導入時の記載ルール

- 山括弧の例を、コード、設定、マニフェスト、CI、README、テストから確認した事実へ置き換える。
- 該当しない項目や未導入のコマンドは削除する。
- 導入完了時に山括弧のプレースホルダーを残さない。
- 推測した仕様、秘密値、個人情報、実運用データを記載しない。
- 詳細を別文書で管理する場合は内容を複製せず、参照先とAIの判断に必要な要点だけを記載する。
